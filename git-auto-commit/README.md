# git-auto-commit

To use this extension, simply save your file in a repo that has an active git repo in it. to ensure that we do not screw up other projects on your computer,
this extension specifically looks that your workspace path contains `ECE-327` or `ECE327`. If you do not have this, this extension will NOT fire. please edit
the parent folder of your projects! This extension run when one of two hotkeys are pressed <br>
Windows & Linux: `ctrl + s` <br>
Mac: `cmd + s` <br>

Want changes? Please open a PR on the parent repo, or reach out to me directly at amwhayho@uwaterloo.ca. My testing was pretty limited, as I made this extension
quicky and didn't rigorously go through any tests!
